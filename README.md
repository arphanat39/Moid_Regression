# การทำนายระยะ MOID ของดาวเคราะห์น้อยด้วยแบบจำลอง Regression

## 1. ภาพรวมโครงงาน (Project Overview)

โครงงานนี้พัฒนาแบบจำลอง Machine Learning ประเภท Regression เพื่อทำนายระยะ **Minimum Orbit Intersection Distance (MOID)** ระหว่างวงโคจรของดาวเคราะห์น้อยกับวงโคจรของโลก โดยใช้คุณลักษณะทางกายภาพและพารามิเตอร์วงโคจรของดาวเคราะห์น้อยเป็นinput 

คำถามหลักของโครงงานคือ

> เราสามารถใช้คุณลักษณะทางกายภาพและพารามิเตอร์วงโคจรหลายตัวของดาวเคราะห์น้อย เพื่อทำนายระยะ MOID ระหว่างวงโคจรของดาวเคราะห์น้อยกับวงโคจรของโลกได้หรือไม่

แบบจำลองรับข้อมูลนำเข้าหลายตัวแปรและทำนายผลลัพธ์ที่เป็นค่าตัวเลขต่อเนื่องหนึ่งค่า

## ประโยชน์ของโปรเจกต์
1. ช่วยประเมินความใกล้เคียงของวงโคจรดาวเคราะห์น้อยกับโลก
แบบจำลองทำนายค่า MOID (Minimum Orbit Intersection Distance) ซึ่งมีหน่วยเป็น AU (Astronomical Unit) โดยใช้ลักษณะทางกายภาพและพารามิเตอร์วงโคจรของดาวเคราะห์น้อย เช่น eccentricity, semi-major axis และ inclination
เมื่อทราบค่า MOID จะช่วยให้เห็นภาพว่าระยะห่างที่น้อยที่สุดระหว่างวงโคจรของดาวเคราะห์น้อยกับวงโคจรโลกมีค่าเท่าใด
2. ช่วยคัดกรองและจัดลำดับดาวเคราะห์น้อยเพื่อการศึกษาเพิ่มเติม
แบบจำลองสามารถใช้ประมาณค่า MOID ของดาวเคราะห์น้อยจากข้อมูลที่มีอยู่ เพื่อช่วยจัดกลุ่มหรือจัดลำดับวัตถุที่ควรนำไปวิเคราะห์เชิงลึกต่อ โดยเฉพาะวัตถุที่มีค่า MOID ต่ำ
อย่างไรก็ตาม ค่า MOID ต่ำเพียงอย่างเดียวไม่ได้หมายความว่าดาวเคราะห์น้อยจะชนโลก และไม่สามารถใช้ยืนยันความเสี่ยงการชนได้โดยตรง
3. แสดงให้เห็นถึงการประยุกต์ใช้ Machine Learning กับข้อมูลทางดาราศาสตร์
โปรเจกต์นี้นำข้อมูลดาวเคราะห์น้อยจำนวนมากจากชุดข้อมูล NASA/JPL มาใช้สร้างแบบจำลอง Regression เพื่อเรียนรู้ความสัมพันธ์ระหว่างคุณลักษณะของดาวเคราะห์น้อยกับค่า MOID
นอกจากนี้ ยังสามารถเปรียบเทียบประสิทธิภาพของแบบจำลองหลายชนิดด้วย MAE, RMSE และ \(R^2\) เพื่อพิจารณาว่าแบบจำลองใดทำนายได้เหมาะสมที่สุด
4. พัฒนาเป็นเครื่องมือทำนายที่ใช้งานได้จริง
เมื่อบันทึกแบบจำลองที่ผ่านการฝึกแล้วและนำไปใช้งานผ่านเว็บไซต์ ผู้ใช้สามารถกรอกคุณลักษณะของดาวเคราะห์น้อยและรับค่าประมาณ MOID ได้ โดยไม่จำเป็นต้องเขียนโค้ดหรือฝึกโมเดลใหม่ทุกครั้ง

## 2. ตัวแปรเป้าหมาย (Target Variable)

ตัวแปรเป้าหมายของแบบจำลองคือ **MOID**

MOID ย่อมาจาก Minimum Orbit Intersection Distance หมายถึงระยะห่างต่ำสุดระหว่างวงโคจรของดาวเคราะห์น้อยกับวงโคจรของโลก

หน่วยของค่าที่ใช้ทำนายคือ **Astronomical Unit (AU)** หรือหน่วยดาราศาสตร์ โดยเว็บแอปพลิเคชันจะแปลงค่าที่ทำนายได้เป็นกิโลเมตรเพื่อให้อ่านและทำความเข้าใจได้ง่ายขึ้น
MOID ไม่ใช่ค่าความน่าจะเป็นที่ดาวเคราะห์น้อยจะชนโลก แม้ค่า MOID จะมีขนาดเล็ก ก็ไม่ได้หมายความว่าดาวเคราะห์น้อยจะชนโลกอย่างแน่นอน

## 3. ตัวแปรนำเข้า (Input Variables)

แบบจำลองใช้ตัวแปรนำเข้าทั้งหมด 8 ตัว ดังนี้

| ตัวแปร | ความหมาย | หน่วย |
|---|---|---|
| `H` | โชติมาตรสัมบูรณ์ (Absolute Magnitude) | magnitude |
| `albedo` | ค่าสะท้อนแสงของพื้นผิว (Surface Reflectivity) | อัตราส่วน |
| `e` | ความเยื้องศูนย์กลางของวงโคจร (Orbital Eccentricity) | ไม่มีหน่วย |
| `a` | กึ่งแกนเอกของวงโคจร (Semi-major Axis) | AU |
| `i` | ความเอียงของวงโคจร (Orbital Inclination) | องศา |
| `om` | ลองจิจูดของจุดโหนดขึ้น (Longitude of Ascending Node) | องศา |
| `w` | มุมระหว่างจุดใกล้ดวงอาทิตย์ที่สุดกับจุดโหนดขึ้น (Argument of Periapsis) | องศา |
| `ma` | มุมเฉลี่ยของดาวเคราะห์น้อยในวงโคจร (Mean Anomaly) | องศา |

สรุปการทำงานของแบบจำลอง

- ข้อมูลนำเข้า: คุณลักษณะของดาวเคราะห์น้อย 8 ตัวแปร
- แบบจำลอง: Regression Model ที่ผ่านการฝึก
- ผลลัพธ์: ค่าทำนาย MOID ซึ่งเป็นตัวเลขต่อเนื่อง

## 4. ตัวแปรที่ไม่นำมาใช้ (Removed Variables)

มีตัวแปรบางตัวที่ถูกตัดออกจากชุดคุณลักษณะสำหรับฝึกแบบจำลอง ด้วยเหตุผลด้านการรั่วไหลของข้อมูลเป้าหมาย ความซ้ำซ้อน หรือการใช้ตัวแปรที่ไม่เหมาะสม

### 4.1 `moid_ld`

ตัวแปร `moid_ld` แสดงค่า MOID ในหน่วยระยะทางจากโลกถึงดวงจันทร์ จึงมีข้อมูลเดียวกันกับตัวแปรเป้าหมายในอีกหน่วยหนึ่ง

หากนำตัวแปรนี้มาใช้เป็นข้อมูลนำเข้า แบบจำลองอาจเรียนรู้จากค่าที่เป็นตัวแทนของคำตอบโดยตรง ทำให้เกิด **Target Leakage** และทำให้ผลการประเมินไม่น่าเชื่อถือ

### 4.2 `q`

ตัวแปร `q` คือระยะใกล้ดวงอาทิตย์ที่สุดของวงโคจร (Perihelion Distance) ซึ่งสัมพันธ์กับกึ่งแกนเอกและความเยื้องศูนย์กลางของวงโคจรตามสมการ

`q = a(1 - e)`

ดังนั้น เมื่อใช้ `a` และ `e` อยู่แล้ว ตัวแปรนี้จึงมีข้อมูลซ้ำซ้อนบางส่วน

### 4.3 `ad`

ตัวแปร `ad` คือระยะไกลดวงอาทิตย์ที่สุดของวงโคจร (Aphelion Distance) ซึ่งสัมพันธ์กับตัวแปรอื่นตามสมการ

`ad = a(1 + e)`

จึงถูกตัดออก

### 4.4 `n`

ตัวแปร `n` คือ Mean Motion ซึ่งสัมพันธ์กับกึ่งแกนเอกและคาบการโคจรตามกฎของเคปเลอร์ จึงมีความสัมพันธ์กับตัวแปรวงโคจรอื่นที่ใช้ในแบบจำลอง

### 4.5 `per` และ `per_y`

ตัวแปรเหล่านี้แสดงคาบการโคจร (Orbital Period) ในหน่วยเวลาที่แตกต่างกัน โดยมีความสัมพันธ์อย่างใกล้ชิดกับกึ่งแกนเอกของวงโคจร

### 4.6 ตัวแปรระบุข้อมูล (ID Variables)

ตัวแปร เช่น รหัสวัตถุ ชื่อดาวเคราะห์น้อย และรหัสวงโคจร ไม่ได้นำมาใช้เป็นตัวแปรทำนาย เนื่องจากใช้ระบุข้อมูลแต่ละรายการมากกว่าการอธิบายคุณลักษณะทางกายภาพโดยตรง

## 5. การเตรียมข้อมูล (Data Preprocessing)

กระบวนการเตรียมข้อมูลประกอบด้วยขั้นตอนต่อไปนี้

1. อ่านข้อมูลจากไฟล์ CSV
2. ตรวจสอบว่ามีคอลัมน์ที่จำเป็นครบถ้วน
3. แปลงตัวแปรที่ต้องใช้ให้อยู่ในรูปแบบตัวเลข
4. ตรวจสอบและจัดการค่าตัวแปรเป้าหมายที่ไม่ถูกต้อง
5. ตรวจสอบข้อมูลซ้ำ
6. ตรวจสอบค่าที่หายไป (Missing Values)
7. ใช้ค่ามัธยฐาน (Median Imputation) เพื่อจัดการค่าที่หายไปของตัวแปรนำเข้า
8. แบ่งข้อมูลเป็นชุดฝึกและชุดทดสอบ
9. ฝึกขั้นตอนการเตรียมข้อมูลด้วยชุดฝึกเท่านั้น
10. ประเมินแบบจำลองด้วยชุดทดสอบที่ไม่ได้ใช้ในการฝึก

สัดส่วนการแบ่งข้อมูลที่กำหนดไว้คือ

- ชุดฝึก (Training Set): 80%
- ชุดทดสอบ (Testing Set): 20%

การแยกชุดข้อมูลมีจุดประสงค์เพื่อประเมินความสามารถในการทำนายข้อมูลที่แบบจำลองไม่เคยพบระหว่างการฝึก ทั้งนี้ ต้องตรวจสอบให้แน่ใจว่าการแบ่งข้อมูลในโค้ดจริงตรงกับสัดส่วนที่ระบุไว้

## 6. การสำรวจข้อมูล (Exploratory Data Analysis: EDA)

โครงงานมีการสำรวจข้อมูลเบื้องต้นเพื่อทำความเข้าใจลักษณะและการกระจายตัวของข้อมูล ก่อนนำไปฝึกแบบจำลอง โดยประกอบด้วย

- สถิติเชิงพรรณนา (Descriptive Statistics)
- การตรวจสอบค่าที่หายไป
- การวิเคราะห์การกระจายตัวของ MOID
- การวิเคราะห์การกระจายตัวของตัวแปรนำเข้า
- การสร้างแผนภาพเมทริกซ์สหสัมพันธ์ (Correlation Matrix)
- การศึกษาความสัมพันธ์ระหว่างตัวแปรนำเข้ากับ MOID
- การตรวจสอบค่าผิดปกติ (Outliers)

ไฟล์กราฟและผลลัพธ์จากการสำรวจข้อมูลจะจัดเก็บไว้ในโฟลเดอร์ `outputs/` ตามที่กำหนดในโค้ด

## 7. แบบจำลอง Regression ที่ใช้

โครงงานเปรียบเทียบแบบจำลอง Regression หลายประเภท เพื่อเลือกแบบจำลองที่เหมาะสมกับข้อมูลและโจทย์การทำนาย

### 7.1 Linear Regression

ใช้เป็นแบบจำลองพื้นฐาน (Baseline Model) เพื่อเป็นจุดอ้างอิงสำหรับเปรียบเทียบประสิทธิภาพกับแบบจำลองที่สามารถเรียนรู้ความสัมพันธ์แบบไม่เชิงเส้นได้

### 7.2 Random Forest Regressor

เป็นแบบจำลอง Ensemble ที่รวมผลจากต้นไม้ตัดสินใจหลายต้น สามารถเรียนรู้ความสัมพันธ์ที่ซับซ้อนและไม่เป็นเชิงเส้นระหว่างตัวแปรนำเข้าและตัวแปรเป้าหมายได้

### 7.3 Gradient Boosting Regressor

เป็นแบบจำลอง Ensemble ที่สร้างตัวเรียนรู้ต่อเนื่องกัน โดยพยายามลดข้อผิดพลาดจากการทำนายของแบบจำลองก่อนหน้าในแต่ละขั้นตอน

### 7.4 HistGradientBoostingRegressor

เป็นแบบจำลอง Gradient Boosting ที่ใช้วิธีแบ่งค่าข้อมูลเป็นช่วงด้วยฮิสโตแกรม เพื่อช่วยเพิ่มประสิทธิภาพในการฝึก โดยเฉพาะเมื่อมีข้อมูลจำนวนมาก

## 8. การประเมินแบบจำลอง (Evaluation Metrics)

ใช้ตัวชี้วัดหลัก 3 ตัวในการประเมินและเปรียบเทียบประสิทธิภาพของแบบจำลอง

### 8.1 MAE — Mean Absolute Error

ค่าเฉลี่ยของความคลาดเคลื่อนสัมบูรณ์ระหว่างค่าจริงกับค่าที่แบบจำลองทำนาย

- ค่ายิ่งต่ำยิ่งดี
- ใช้อธิบายขนาดความคลาดเคลื่อนโดยเฉลี่ยได้โดยตรง
- มีหน่วยเดียวกับตัวแปรเป้าหมาย คือ AU หากประเมินในหน่วย AU

### 8.2 RMSE — Root Mean Squared Error

รากที่สองของค่าเฉลี่ยกำลังสองของความคลาดเคลื่อนระหว่างค่าจริงกับค่าที่ทำนาย

- ค่ายิ่งต่ำยิ่งดี
- ให้ความสำคัญกับข้อผิดพลาดขนาดใหญ่ได้มากกว่า MAE
- มีหน่วยเดียวกับตัวแปรเป้าหมาย คือ AU หากประเมินในหน่วย AU

### 8.3 R² — Coefficient of Determination

ค่าสัมประสิทธิ์การกำหนด ใช้วัดว่าแบบจำลองสามารถอธิบายความแปรปรวนของตัวแปรเป้าหมายได้มากน้อยเพียงใด เมื่อเทียบกับเกณฑ์อ้างอิงของการทำนายด้วยค่าเฉลี่ย

- โดยทั่วไป ค่ายิ่งสูงยิ่งดี
- ค่าใกล้ 1 หมายถึงแบบจำลองอธิบายความแปรปรวนได้ดี
- ค่าใกล้ 0 หมายถึงประสิทธิภาพใกล้เคียงกับการทำนายด้วยค่าเฉลี่ยในแง่ของ R²
- ค่าติดลบหมายถึงแบบจำลองทำได้แย่กว่าเกณฑ์อ้างอิงดังกล่าวบนชุดข้อมูลที่ประเมิน

## 9. การเลือกแบบจำลอง (Model Selection)

แบบจำลองแต่ละประเภทจะถูกเปรียบเทียบโดยใช้ตัวชี้วัดจากชุดทดสอบตามกระบวนการที่กำหนดไว้ในโค้ด

การเลือกแบบจำลองสุดท้ายควรพิจารณาความคลาดเคลื่อนและความสามารถในการทำนายโดยรวม โดยใช้ MAE เป็นตัวชี้วัดหลัก และใช้ RMSE กับ R² เป็นตัวชี้วัดประกอบ

ผลการเปรียบเทียบแบบจำลองจะบันทึกไว้ในไฟล์

## 10. การวิเคราะห์ข้อผิดพลาด (Error Analysis)

โครงงานวิเคราะห์ข้อผิดพลาดของแบบจำลอง เพื่อศึกษาความแตกต่างระหว่างค่าจริงกับค่าที่ทำนาย โดยประกอบด้วย

- กราฟเปรียบเทียบค่าจริงกับค่าทำนาย (Actual vs. Predicted)
- กราฟค่าคงเหลือ (Residual Plot)
- การวิเคราะห์ค่าความคลาดเคลื่อนสัมบูรณ์
- การตรวจสอบตัวอย่างที่มีค่าความคลาดเคลื่อนสูงที่สุด

ผลการวิเคราะห์ตัวอย่างที่มีข้อผิดพลาดสูงจะบันทึกไว้ใน

`outputs/prediction_errors.csv`

ช่วยให้เข้าใจข้อจำกัดของแบบจำลองและระบุลักษณะข้อมูลที่แบบจำลองยังทำนายได้ไม่แม่นยำ

## 11. ความสำคัญของตัวแปร (Feature Importance)

สำหรับแบบจำลองที่รองรับการคำนวณ Feature Importance โครงงานจะวิเคราะห์ความสำคัญของตัวแปรนำเข้าแต่ละตัว เพื่อศึกษาว่าตัวแปรใดมีส่วนช่วยในการทำนายตามเกณฑ์ของแบบจำลองนั้น

ผลลัพธ์จะจัดเก็บไว้ใน

- `outputs/feature_importance.csv`
- `outputs/feature_importance.png`

Feature Importance แสดงความสำคัญของตัวแปรภายใต้แบบจำลองที่ฝึก ไม่ได้ยืนยันว่าตัวแปรนั้นเป็นสาเหตุโดยตรงของค่า MOID

## 12. การบันทึกแบบจำลอง (Model Saving)

แบบจำลองที่ผ่านการฝึกจะถูกบันทึกไว้ในไฟล์

`model/moid_model.joblib`

หากใช้ Pipeline ขั้นตอนการเตรียมข้อมูลที่จำเป็น เช่น การจัดการค่าที่หายไป จะถูกบันทึกไว้ร่วมกับแบบจำลองตามที่กำหนดในโค้ด

เว็บแอปพลิเคชันจะโหลดแบบจำลองที่บันทึกไว้เพื่อทำนายผล โดยไม่ต้องฝึกแบบจำลองใหม่ทุกครั้งที่ผู้ใช้ส่งข้อมูล

## 13. เว็บแอปพลิเคชัน (Web Application)

เว็บแอปพลิเคชันพัฒนาด้วย Gradio เพื่อให้ผู้ใช้สามารถทดลองทำนายค่า MOID ผ่านหน้าเว็บได้

### ข้อมูลที่ผู้ใช้ต้องป้อน

- `H`
- `albedo`
- `e`
- `a`
- `i`
- `om`
- `w`
- `ma`

### ผลลัพธ์ที่แสดง

- ค่า MOID ที่ทำนายได้ในหน่วย AU
- ค่า MOID ที่แปลงเป็นกิโลเมตร

เว็บแอปช่วยให้ผู้ใช้ทดลองเปลี่ยนค่าตัวแปรนำเข้าและสังเกตผลการทำนายได้โดยไม่ต้องเรียกใช้โค้ดฝึกแบบจำลองโดยตรง

**ข้อจำกัด:** ผลลัพธ์เป็นค่าที่แบบจำลองคำนวณจากข้อมูลและรูปแบบที่เรียนรู้ระหว่างการฝึก ไม่ใช่การคำนวณวงโคจรทางดาราศาสตร์โดยตรง และไม่ควรนำไปใช้สรุปความน่าจะเป็นในการชนโลก

## 14. วิธีติดตั้งและเรียกใช้งาน (How to Run)

### 14.1 ติดตั้ง Python Dependencies

เปิด Terminal หรือ PowerShell ในโฟลเดอร์หลักของโครงงาน แล้วรันคำสั่ง

```bash
pip install -r requirements.txt
```

### 14.2 เรียกใช้เว็บแอปพลิเคชัน

รันคำสั่ง

```bash
python app.py
```

จากนั้นเปิด URL ที่ Gradio แสดงใน Terminal เพื่อทดลองใช้งานเว็บแอปบนเครื่อง

### 14.3 การฝึกแบบจำลองใหม่

หากต้องการฝึกแบบจำลองใหม่ ให้ตรวจสอบว่ามีชุดข้อมูลและไฟล์ที่จำเป็นครบถ้วนก่อน แล้วเรียกใช้สคริปต์ฝึกตามคำสั่งที่กำหนดไว้ใน `train.py`

**หมายเหตุ:** ขั้นตอนการฝึกใหม่จำเป็นต้องใช้ชุดข้อมูลต้นฉบับ หากไม่ได้เก็บไฟล์ CSV ไว้ใน GitHub ผู้ใช้ต้องดาวน์โหลดชุดข้อมูลจากแหล่งที่ระบุไว้ในหัวข้อถัดไปก่อนฝึกแบบจำลองใหม่

## 17. ข้อจำกัดของโครงงาน (Limitations)

1. ประสิทธิภาพของแบบจำลองขึ้นอยู่กับคุณภาพ ความครบถ้วน และการกระจายตัวของข้อมูลที่ใช้ฝึก
2. แบบจำลองอาจทำนายได้คลาดเคลื่อนสำหรับข้อมูลที่มีลักษณะแตกต่างจากข้อมูลฝึก
3. ค่าความสำคัญของตัวแปรไม่ใช่หลักฐานของความสัมพันธ์เชิงสาเหตุ
4. MOID ไม่ใช่ความน่าจะเป็นในการชนโลก และผลการทำนายไม่ใช่การประเมินความเสี่ยงการชนอย่างเป็นทางการ
5. ผลการประเมินควรอ้างอิงค่าจริงจากชุดทดสอบที่แยกไว้โดยไม่ใช้ฝึกหรือปรับเลือกแบบจำลอง
